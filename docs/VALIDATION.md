# v0.2 验证范围

日期：2026-10-30。当前运行验证基线为 Windows 上实际安装的 **DSH 0.2.1-rc.5**。

最终源码的类型检查、108 项自动测试和前后端构建均通过。真实 rc.5 控制注册表集成测试通过下述 8 项检查，人工页面验收确认管理页、市场页及详情页均提供单一更新入口，详情页没有重复页头按钮。发行附件的 SHA-256 以对应 `.sha256` 文件为准。

## rc.5 控制注册表集成

项目隔离环境中的真实 DSH SDK/包管理链路已通过以下场景：

- 将预编译包安装到独立 profile，验证 Owner 认证及跨源修改拒绝。
- 保留核心、市场、自身和原先关闭的插件；旧停用/恢复兼容链路可以跨进程重启接续。
- 在本地控制 npm 注册表中顺序更新测试插件：A、C、D 从 1.0.0 更新到 1.1.0；B 更新失败后成功回滚到 1.0.0，之后继续 C、D。
- D 原先关闭，更新后仍不在启用列表中；其插件代码在该更新场景中没有执行。
- 实际 rc.5 进程重启后，更新结果及 B 的回滚结果仍可读取。

上述结果对应 `.dev/integration-report.json` 和 `tooling/integration.mjs --market --updates` 的检查。`.dev` 中的运行报告只作本地证据，不进入发行包。控制注册表不会访问或修改用户的日常插件集合。

## 验证边界

- 没有逐一验证全部社区插件、所有依赖图、安装脚本或卸载清理行为。
- 实际安装遵守官方 SDK/pnpm 的 `minimumReleaseAge` 等策略，查询最新与实际安装版本可能不同。
- 回滚为尽力恢复，不保证撤销第三方脚本、数据变更或完整运行状态。未完成项必须继续保留恢复责任。
- 公开启用 API 可能改变 bundle 的追加顺序，不能保证完整配置优先顺序原样复原。
- 本记录不代表已执行公开发布、npm 发布、社区收录或日常插件的一键更新。
